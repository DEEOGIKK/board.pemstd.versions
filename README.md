## 🛠 Instalasi (Windows)

1. Buka halaman [Releases](https://github.com/DEEOGIKK/board.pemstd.versions/releases) dan unduh installer versi yang kamu mau.
2. Jalankan file `.exe` yang sudah diunduh, lalu ikuti petunjuk di layar.
3. Jika Windows menampilkan peringatan **SmartScreen**, klik **More info → Run anyway**.
4. Buka **PEMSTD BOARD**, buat project baru (`Ctrl+S`) atau buka file project lokal yang sudah ada.

> Mau pindah versi? Cukup install versi lain di atas versi lama. Project kamu tersimpan sebagai file di drive sendiri, jadi aman dari proses ini.

## ✨ Fitur

- **Kanban 3 kolom** — Available, Today, dan Completed, dengan drag & drop.
- **Task node** — tiap task punya catatan rich text, subtask, arsip, dan hapus.
- **Local-first** — data tersimpan sebagai file di drive-mu, tanpa akun dan tanpa cloud.
- **Cepat** — tidak ada loading lambat, berjalan mulus di perangkatmu.
- **Bersih** — gratis, tanpa iklan, bloatware, ataupun malware tersembunyi.
- **Fokus personal** — dirancang untuk solo-developer dan kreator, bukan manajemen organisasi besar.
